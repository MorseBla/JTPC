Differences that must remain distinct
1. Original Figure 7(b) FIXED_RTR is 0.70; body/caption say 0.90. All 15 power bar heights match the 0.70 data.
2. Figure 7(a) raw DFS mean RTR values are 15.988110, 16.190574, 16.446622, 11.629850, 14.485548. All five bars are clipped by the 1.0 upper axis limit; their visible height does not imply RTR near 1.
3. Figure 8 initial periods are [160,80,60] ms; Figure 9 initial mm is also 60 ms. The body specifies mm=80 ms. Figures 4/5/6 use [160,80,80] ms, matching that section's body.
4. The four paper eigenvalues are nominal A-BK values from robustness_check_B_noise.py, not a Gaussian-perturbation realization. Later script perturbations are +/-5% uniform; the paper says multiplicative Gaussian.
5. Current remote compute_LQR_gain_2 uses an identity upper-left B block. The offline stability example uses zero-diagonal, measured off-diagonal coupling. Current code and the paper cannot be treated as one frozen version.
6. The quoted 13.51% comes from an older DMR table: average across five power targets at each RTR, using [100:-1] for long logs. It is not the fixed-11-W Figure 7(a) statistic. Old notebook output lists FC all zero; the same code on current files yields 0.015312% and 0.004252% in the first two columns. Distinguish output/data versions.
7. The device currently identifies as Jetson Orin Nano Engineering Reference Developer Kit Super, CUDA 12.6.85, L4T 36.4.3; the paper says CUDA 12.0. Current readings do not disprove a historical installation, but a frozen environment record is missing.
8. Current capture supports INA260/jtop/tegrastats, defaulting to tegrastats VDD_IN; power-offset settings and older sensor branches also exist. INA260 source alone does not establish that all paper data used INA260, or that it measured a separate GPU supply rail.

Project chain

Experiment scripts were not executed: some historical entries clear logs, kill processes, and alter device clocks. This audit was read-only.
