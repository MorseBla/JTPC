JTPC: GitHub source control and rsync results

No build is needed for these tools. Dependencies: Git, Python 3.9+, SSH,
local rsync >=3.2.3, rsync on thor2, and GitHub authentication on both machines.
Local Git is initialized on main. GitHub creation/push and thor2 setup remain
pending: this Codex session cannot open network sockets or log in to GitHub.

ONE-TIME LOCAL SETUP
Create a PRIVATE, empty repository named JTPC at https://github.com/new.
Do not initialize README, .gitignore, or license. If the name is taken, choose
another name and adjust the URL below. Replace YOUR_GITHUB_USERNAME and
YOUR NAME with your actual values. Only configure the name if it is missing.

cd ~/Documents/JTPC/JTPC
git config --get user.name
git config user.name "YOUR NAME"
git status --short
git diff --cached --stat

If an initial commit has not yet been created:
git add .
git commit -m "Initial JTPC source and synchronization setup"

After creating the empty private GitHub repository:
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/JTPC.git
git push -u origin main

If origin already exists, inspect git remote -v rather than repeating add.
GitHub passwords cannot authenticate Git. Use your credential manager, a scoped
token at the password prompt, or an installed GitHub CLI:
gh auth login
gh auth setup-git
Never put tokens in files here or in remote URLs. Authentication guidance:
https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/about-authentication-to-github

DAILY SOURCE WORKFLOW (ON EITHER MACHINE)
From the project's directory, with a clean working tree, before editing:
git pull --ff-only

After editing, substitute real filenames and a useful message:
git status
git add path/to/changed_file
git diff --cached
git commit -m "Describe the change"
git push

Commit/push before switching machines; pull on the other before continuing.
Git transfers committed files only. If branches diverge, review and reconcile
them; do not discard edits or force push to work around the divergence.

cd ~/Documents/JTPC/JTPC
